Spinwell 是一款 Android 上的 Navidrome 播放器：輕巧、快速、好看，沒有廣告。它可以把你伺服器上的音樂收藏串流播放，也可以下載下來離線收聽。除了 Navidrome，它也支援任何使用 OpenSubsonic 或 Subsonic API 的伺服器。輸入伺服器網址、使用者名稱和密碼登入後，你的專輯、歌手和播放清單就都在這裡了。

收聽
• 以原始音質串流播放歌曲（包括 FLAC），使用行動數據時也可以選擇較低的音質
• 可以透過鎖定畫面、通知、耳機和藍牙控制播放
• 同步歌詞會跟著歌曲捲動，點一下某一行就能跳到那裡
• 智慧隨機播放不會讓同一位歌手的歌曲連著播放兩次
• 「接下來播放」清單可以調整順序，每首歌都有「下一首播放」和「加入佇列」
• 從上次停下的地方繼續：歌曲、佇列和播放進度都會保留

你的音樂庫
• 首頁會顯示最近播放、最近加入、播放最多和收藏的專輯
• 歌手、專輯、播放清單、歌曲和收藏，搭配清晰的大封面
• 搜尋會在你輸入時就找出歌手、專輯和歌曲，不區分大小寫和重音符號
• 收藏會與你的伺服器同步
• 你的播放紀錄會回報到你的伺服器，所以播放次數和歷史紀錄始終準確；你也可以關閉這項功能

離線
• 可以下載單曲、專輯、播放清單，或某位歌手的全部歌曲；中斷的下載會從停下的地方繼續
• 可以保留原始檔案，也可以儲存體積更小的 MP3
• 無法連上伺服器時（例如關閉了 Tailscale），Spinwell 會自動切換到你已下載的內容，連線恢復後再自動跟上最新狀態
• 所有下載項目都能在同一個地方查看和移除

重視隱私
Spinwell 只會與你登入的伺服器連線。不需要註冊我們的帳號，沒有資料分析、沒有廣告，也沒有追蹤。這個 App 免費且開放原始碼。

使用 Spinwell 需要一台由你或你認識的人架設的 Navidrome 或 OpenSubsonic 伺服器。Spinwell 是獨立的 App，與 Navidrome 專案沒有隸屬關係，也未獲得其認可。
