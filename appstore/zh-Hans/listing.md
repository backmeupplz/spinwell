## Description (max 4000)
Spinwell 是一款 iPhone 上的 Navidrome 播放器：小巧、快速、好看，没有广告。它可以把你服务器上的音乐收藏在线播放，也可以下载下来离线收听。除了 Navidrome，它也支持任何使用 OpenSubsonic 或 Subsonic API 的服务器。输入服务器地址、用户名和密码登录后，你的专辑、歌手和播放列表就都在这里了。

收听
• 以原始音质播放歌曲（包括 FLAC），使用移动数据时也可以选择较低的音质
• 可以通过锁定屏幕、控制中心、耳机和 AirPlay 控制播放
• 同步歌词会跟着歌曲滚动，点一下某一行就能跳到那里
• 智能随机播放不会让同一位歌手的歌曲连着播放两次
• “接下来播放”列表可以调整顺序，每首歌都有“下一首播放”和“添加到队列”
• 从上次停下的地方继续：歌曲、队列和播放进度都会保留

你的音乐库
• 首页会显示最近播放、最近添加、播放最多和收藏的专辑
• 歌手、专辑、播放列表、歌曲和收藏，配上清晰的大封面
• 搜索会在你输入时就找出歌手、专辑和歌曲，不区分大小写和重音符号
• 收藏会与你的服务器同步
• 你的播放记录会上报到你的服务器，所以播放次数和历史记录始终准确；你也可以关闭这项功能

离线
• 可以下载单曲、专辑、播放列表，或某位歌手的全部歌曲；中断的下载会从停下的地方继续
• 可以保留原始文件，也可以保存体积更小的 MP3
• 连不上服务器时（比如关闭了 Tailscale），Spinwell 会自动切换到你已下载的内容，连接恢复后再自动跟上最新状态
• 所有下载都能在同一个地方查看和删除

注重隐私
Spinwell 只与你登录的服务器通信。无需注册我们的账号，没有统计分析，没有广告，也没有追踪。本应用免费且开源。

使用 Spinwell 需要一台由你或你认识的人运行的 Navidrome 或 OpenSubsonic 服务器。Spinwell 是一款独立应用，与 Navidrome 项目没有关联，也未获得其认可。
